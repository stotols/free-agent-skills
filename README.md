# Free skills & sections for AI coding agents

Small, finished things for people who build with AI coding agents
(Claude Code, Codex, Cursor, Gemini CLI). No "prompt harder" advice —
just instruction files and working code you can drop in today.

Made by [S Tools Lab](https://kurove.gumroad.com).

## What's here

### 1. `landing-page/` — a design Skill for landing pages

A SKILL.md instruction set that makes your agent build landing pages with
an actual design system — one accent color, a type scale, layout recipes,
copy rules, an anti-pattern list, and a QA checklist — instead of the
generic "AI-generated page" look.

Includes a finished example (HTML + rendered preview) for a fictional
product, "Pulse", so you can judge the target quality before installing
anything.

**Install:** copy the `landing-page` folder into your agent's skills
directory (Claude Code: `~/.claude/skills/`), restart the agent, and ask
it to build a landing page.

### 2. `agent-ready-hero/` — a website section your agent can edit

A Hero section in clean HTML + Tailwind, shipped with an `AGENT.md` file
that tells your agent exactly how the section is structured and what it
may change. Working code first, instructions attached — so the next edit
doesn't wreck the layout.

**Use:** open `index.html` to preview, then hand the folder to your agent
and ask for copy or color changes.
